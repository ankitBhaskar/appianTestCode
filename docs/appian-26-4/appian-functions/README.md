## Purpose

This folder contains APN engineering guidance for Appian 26.4 functions and function usage in SAIL, expressions, records, processes, integrations and AI-generated code review.

## How to use this folder

Use these files as safe engineering guidance. For exact function signatures, parameters, return types, examples, compatibility notes and version changes, always check the official Appian documentation.
